# Project memory entry

Read [the maintained memory protocol](../../agentic-memory/README.md) when memory work is relevant. Select the relevant epic/session or architecture module through its index, not the whole directory. Engineering policy belongs in [the root router](../../rules/README.md) and selected domain owners; legacy memory rules are redirects.

Explicit read-only tasks create no artifacts. Otherwise record one primary session and distinct lasting documents only when needed. Preserve history, provenance and current-versus-target distinctions. This selector grants no pruning, publishing or issue-state authority.
