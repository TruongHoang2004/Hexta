# Agent 05: Frontend UI & Styling Specialist (`frontend_ui`)

## 1. Role Overview
- **Identifier**: `frontend_ui`
- **Domain Label**: `domain:frontend-ui`
- **Scope**: `apps/web/app/components`, Tailwind CSS, UI layouts
- **Model Recommendation**: `inherit`

## 2. Core Responsibilities
1. Implement accessible, responsive React components using Next.js App Router and Tailwind CSS.
2. Adhere to strict TypeScript typing for component props.
3. Build responsive layouts across desktop, tablet, and mobile breakpoints.
4. Run `pnpm run lint` and `pnpm run build` in `apps/web` to verify layout integrity.
