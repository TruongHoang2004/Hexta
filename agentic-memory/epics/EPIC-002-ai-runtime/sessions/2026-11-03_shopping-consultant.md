# Go and web shopping consultant integration

## Scope

Integrate the owner-specified Python consult HTTP contract into Go SSE and a Next.js
shopping widget/checkout. Cross-domain sales consumer belongs to EPIC-007; this
session owns the shared evidence. No Python/provider/schema changes or deployment.

## Starting evidence

Branch main, HEAD 2e5f18e, with existing unrelated onboarding/privacy and connector
memory edits preserved. The legacy AI controller/service existed but converse was
not routed. No storefront/checkout routes or checked-in Python consult endpoint
were found. User-supplied Python endpoint contract is the external dependency;
existing durable gRPC runs remain a distinct protocol.

## Outcome and decisions

IMPLEMENTED locally:
- Internal HTTP adapter, explicit token/URL config, bounded timeout/body, caller
  cancellation, safe errors, no redirects/retries; Fx production binding changed
  from the dormant Gemini generator to the consultant service.
- Current tenant/catalog authorization before and after generation; names/prices
  come from Go catalog, variants are resolved explicitly, unknown/ambiguous IDs
  and invalid draft quantities are dropped. No AI output creates an order.
- Authenticated converse route and named SSE events; retained public prompt/history
  input and matching event JSON envelopes. Swagger generated by `make swagger`.
- Storefront, floating widget, safe Markdown, horizontal product cards, optional
  images/placeholder, quick replies, cancellation/errors and draft handoff.
- Checkout reviews refreshed catalog and server totals, selects a current customer,
  assigns the current actor and calls existing versioned sales confirmation.
  Uncertain create failures block immediate resubmission; durable create
  idempotency and reload recovery remain existing sales limitations.
- Reused shared Button/Input, sales classes, SDK auth/refresh/fetch transport,
  workspace gate and sales endpoints. Added react-markdown for safe Markdown
  rendering with raw HTML disabled; no new framework or lockfile.

Contract/configuration, mixed-version deployment and rollback constraints are in
[HTTP owner module](../../../designs/system/04-http-api.md#shopping-consultant-integration--local-2026-11-03).

Selected guidance: cross-service/backend/frontend/component-discovery/dev-changelog
skills; Go conventions, boundaries, controllers, DTO/responses, client/config/Fx,
authorization/errors, routing/services, Swagger and verification rules. Relevant
requirements include ARC-002/003/005, SEC-005/006, SVC-008/009, HTTP-001/005/007,
DI-001, INF-001/006 and QA-001/006. No schema or generated RPC modification.
