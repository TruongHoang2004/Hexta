## 2. Technical Architecture & Test Strategy

### 2.1 TypeScript SDK Tests (`packages/sdk/src/index.test.ts`)
- Use `axios-mock-adapter` and `vitest`.
- Test Suites:
  - **Tenant Management**: `createTenant`, `getTenants`, `getTenant`, `updateTenant`.
  - **Member Operations**: `getUsers`, `inviteMember`.
  - **Token Accessors**: `getAccessToken`, `getRefreshToken`.
  - **Storage Adapters**: Verify `MemoryStorage` and `DefaultBrowserStorage` behavior.
  - **Error Translation**: Validate error message extraction, status preservation, and code propagation.

### 2.2 Go Repository Tests (`services/api/internal/repository/order_repository_test.go`)
- Test Suites:
  - `TestOrderRepository_CRUD`: Test `CreateOrder` with items in transaction, `GetByID` with eager items loading, `GetByOrderNumber`, `ListOrders` with pagination and status filter, `UpdateOrderStatus`, and `UpdatePaymentStatus`.
