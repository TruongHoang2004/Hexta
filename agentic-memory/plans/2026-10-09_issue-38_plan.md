## 1. Overview & Goal
Build the conversational assistant user interface in `apps/web` (Next.js 16 + React 19 + Tailwind CSS) featuring real-time Server-Sent Events (SSE) stream rendering, an Interactive Order Draft Review Card with Human-in-the-Loop "Confirm Order" action, inline item editing (quantity and variant adjustments), and silent token refresh.

### Core UX & Architectural Invariants:
1. **Human-in-the-Loop Confirmation**: Draft orders are presented with prominent visual differentiation from plain text chat. Confirmation explicitly invokes `POST /api/v1/orders` with `draft_id`.
2. **Inline Adjustments**: Store operators can adjust item quantities and variants directly within the draft card before confirming, dynamically updating totals.
3. **Resilient SSE Streaming**: Consumes `POST /api/v1/ai/agent/converse` via `ReadableStream` with automatic 401 recovery (silent token refresh via `@hexta/sdk`).
4. **Collapsible Floating Drawer**: Unobtrusive floating trigger pill/button with expandable drawer accessible across pages.

## 3. Step-by-Step Execution Plan

### Step 3.1: Service Layer (`ai-agent-service.ts`)
- Define TypeScript types: `OrderDraft`, `DraftItem`, `SSEEvent`, `ConverseRequest`.
- Implement `converseStream`:
  - Fetch `POST /api/v1/ai/agent/converse` with `Authorization: Bearer <token>` and `X-Tenant-ID`.
  - Handle 401 Unauthorized with `sdk.identity.refreshToken()` and single retry.
  - Parse SSE chunks (`data: {...}`) and trigger callbacks: `onToken`, `onToolCall`, `onDraftProposed`, `onDone`, `onError`.
- Implement `confirmDraftOrder`:
  - Dispatches `POST /api/v1/orders` with `draft_id`, `items`, `source: "ai_draft"`, `auto_confirm: true`.

### Step 3.2: Hook Layer (`use-ai-agent.ts`)
- Manages message history (`id`, `role`, `content`, `draft`, `status`).
- Provides `sendMessage`, `confirmDraft`, `updateDraftItem`, `discardDraft`.
- Computes real-time totals upon inline quantity modification.

### Step 3.3: Interactive Draft Card Component (`interactive-draft-card.tsx`)
- Distinct card design: border, badges ("Bản nháp đơn hàng AI" / "Chờ xác nhận").
- Displays customer info, item table with +/- quantity controls, unit price, and subtotal.
- "Xác nhận đặt hàng" (Confirm Order) button with loading state.
- Transition to confirmed state showing Order ID / Number and success badge.

### Step 3.4: Chat Drawer Component (`chat-drawer.tsx`)
- Floating launcher button at bottom-right with bot/sparkle icon.
- Slide-over / floating drawer with header, message stream, draft card renderer, input box, and quick prompts.
- Smooth auto-scrolling on streaming tokens.

### Step 3.5: Layout Mounting & Build Verification
- Add `<ChatDrawer />` to `apps/web/app/layout.tsx`.
- Run frontend type check and build (`pnpm --filter web run build` / lint).
- Document review in `agentic-memory/reviews/` and changelog in `agentic-memory/changelogs/`.
