## 1. Overview & Objective
Establish the relational database schema foundation for Hexta's core business domains:
1. **Product Catalog**: `products`, `product_variants`
2. **Inventory Management**: `inventory_items`, `stock_movements`
3. **Order Management**: `orders`, `order_items`
4. **Customer Catalog**: `customers`
5. **Auditability & AI Lineage**: `audit_logs`, `ai_drafts`

All models embed tenant isolation (`tenant_id`), composite indexing, foreign key constraints, and precise decimal types for financial fields.

---

## 2. Technical Analysis & Schema Design

### 2.1. Tenant Isolation
Every model contains:
- `tenant_id` (`varchar(36)` / `uuid`) indexed for tenant scoping.
- Soft delete (`deleted_at`) for products, orders, and customers to preserve transaction history.
- UUID identifiers (`varchar(36)` with `gen_random_uuid()` or string UUIDs).

### 2.2. GORM Models Specification (`services/api/internal/core/model/`)
- `products.go`:
  - `Product`: `id`, `tenant_id`, `name`, `description`, `category`, `status`, `created_at`, `updated_at`, `deleted_at`.
  - `ProductVariant`: `id`, `tenant_id`, `product_id`, `sku` (unique per tenant), `variant_name`, `price`, `cost_price`, `barcode`.
- `inventory.go`:
  - `InventoryItem`: `id`, `tenant_id`, `variant_id` (unique per tenant), `on_hand_qty`, `reserved_qty`, `available_qty`, `safety_threshold`.
  - `StockMovement`: `id`, `tenant_id`, `inventory_id`, `movement_type`, `quantity`, `balance_after`, `reference_type`, `reference_id`, `notes`.
- `orders.go`:
  - `Order`: `id`, `tenant_id`, `order_number` (unique per tenant), `customer_id`, `status`, `payment_status`, `subtotal`, `discount`, `total_amount`, `source`, `draft_id`.
  - `OrderItem`: `id`, `tenant_id`, `order_id`, `variant_id`, `quantity`, `unit_price`, `line_total`.
- `customers.go`:
  - `Customer`: `id`, `tenant_id`, `full_name`, `phone`, `email`, `address`.
- `audit_logs.go`:
  - `AuditLog`: `id`, `tenant_id`, `user_id`, `action`, `entity_type`, `entity_id`, `source`, `draft_id`, `before_state`, `after_state`, `created_at`.
- `ai_drafts.go`:
  - `AIDraft`: `id`, `tenant_id`, `user_id`, `intent`, `prompt`, `draft_payload`, `status`, `expires_at`.

### 2.3. Atlas Integration & Migrations
- Register new models in `services/api/cmd/tools/main.go` for `atlas-provider-gorm`.
- Generate migration SQL file: `migrations/api/20261009180000_create_core_business_schema.sql`.
