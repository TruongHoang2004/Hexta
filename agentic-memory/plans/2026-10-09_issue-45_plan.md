# Implementation Plan: Remove MinIO Service from Docker Compose Infrastructure

- **Issue**: [#45](https://github.com/TruongHoang2004/Hexta/issues/45)
- **Date**: 2026-10-09
- **Branch**: `task/issue-45-chore-infra-remove-minio-service-from-docker-compose`
- **Domain**: `infrastructure`

---

## 1. Overview & Goal
Remove the MinIO object storage service container and its associated port bindings (9000, 9001), volume mounts, environment variables, and documentation references from the local infrastructure configuration.

MinIO is not actively utilized by the core backend microservices (which rely on PostgreSQL, Redis, Elasticsearch, Kafka, and Qdrant). Removing MinIO reduces local developer machine memory/CPU footprint, eliminates port contention on 9000/9001, and cleans up Docker Compose configuration.

---

## 2. Current State Analysis
1. `infrastructure/docker-compose.yml`:
   - Contains `minio` service definition (image `minio/minio:RELEASE.2025-09-07T16-13-09Z-cpuv1`), ports `9000:9000` and `9001:9001`, environment variables `MINIO_ROOT_USER`, `MINIO_ROOT_PASSWORD`, healthchecks, and volume mount `./volumes/minio:/data`.
2. `infrastructure/.env.example`:
   - Contains `MINIO_ROOT_USER=minioadmin` and `MINIO_ROOT_PASSWORD=minioadmin`.
3. `infrastructure/README.md`:
   - References MinIO in the service mapping table and core infrastructure list.
4. `Makefile`:
   - Contains comment mentioning Minio under `infra-up`.
5. Root `README.md`:
   - Contains ASCII topology box for MinIO, port mapping table entries, and start command references.
6. Documentation files:
   - `docs/local-development-guide.md` and `docs/architecture/system-architecture.md` contain port references or architecture references.

## 4. Risk Assessment & Edge Cases
- **Syntax errors in YAML**: Removing YAML blocks can easily introduce indentation errors. We will validate using `docker compose -f infrastructure/docker-compose.yml config`.
- **Dangling service dependencies**: Verify that no other service in `docker-compose.yml` has a `depends_on: [minio]` clause. (Verified: none depend on minio).
- **Backend dependencies**: Check if backend code references MinIO credentials or endpoints directly. (Verified: none in `services/api/internal`).
