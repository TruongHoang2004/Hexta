## 1. Overview & Goal
Build the Inventory Management System (IMS) persistence layer and business service in `services/api`.
The core challenge in SME inventory management is preventing **overselling** under concurrent order placements while maintaining complete **auditability** of physical inventory adjustments.

### Key Capabilities:
1. **Atomic Stock Reservation**: Two-phase reservation model (`Available` $\rightarrow$ `Reserved` $\rightarrow$ `Deducted` / `Released`) using atomic conditional SQL queries.
2. **Stock Movement Ledger**: Every physical mutation (Inbound, Outbound, Adjustment, Return) creates an immutable `StockMovement` record with before/after balance.
3. **Tenant Context Enforced**: Every query strictly isolates records by `tenant_id`.
4. **Uber Fx Integration**: Register `InventoryRepository` and `InventoryService` in the dependency injection container.
5. **Unit Tests**: Full test coverage for concurrent reservation checks and edge cases (e.g. out of stock, negative quantities).

## 2. Technical Architecture & Interfaces

### 2.1. Repository Interface (`services/api/internal/repository/inventory_repository.go`)
```go
type IInventoryRepository interface {
    GetByVariantID(ctx context.Context, tenantID, variantID string) (*model.InventoryItem, *errors.Error)
    CreateInventoryItem(ctx context.Context, item *model.InventoryItem) (*model.InventoryItem, *errors.Error)
    ReserveStock(ctx context.Context, tenantID, variantID string, quantity int) (*model.InventoryItem, *errors.Error)
    ReleaseStock(ctx context.Context, tenantID, variantID string, quantity int) (*model.InventoryItem, *errors.Error)
    DeductStock(ctx context.Context, tenantID, variantID string, quantity int, refType string, refID *string) (*model.InventoryItem, *errors.Error)
    AdjustStock(ctx context.Context, tenantID, variantID string, newOnHand int, notes string) (*model.InventoryItem, *errors.Error)
    ListMovements(ctx context.Context, tenantID, inventoryID string, limit, offset int) ([]*model.StockMovement, *errors.Error)
}
```

### 2.2. Concurrency & Reservation Strategy
When an order is drafted/confirmed, stock reservation executes atomically:
```sql
UPDATE inventory_items
SET 
    reserved_qty = reserved_qty + :quantity,
    available_qty = available_qty - :quantity,
    updated_at = NOW()
WHERE 
    tenant_id = :tenant_id 
    AND variant_id = :variant_id
    AND available_qty >= :quantity;
```
If `RowsAffected == 0`, check if item exists. If it exists with `available_qty < quantity`, return a domain error with code `ERR_INSUFFICIENT_STOCK`.
