## 1. Overview & Goal
Build the Order Management System (OMS) in `services/api` adhering to the 5-layer Clean Architecture.
The OMS coordinates with the Inventory Management System (IMS) to reserve and deduct stock in accordance with the formal **Order Finite State Machine (FSM)**.

### State Machine Transition Rules:
- `Draft` $\rightarrow$ `Confirmed`: Verifies and reserves stock (`inventoryService.ReserveStock`).
- `Draft` $\rightarrow$ `Cancelled`: Discards order draft.
- `Confirmed` $\rightarrow$ `Processing`: Staff packages items.
- `Confirmed` $\rightarrow$ `Cancelled`: Releases reserved stock (`inventoryService.ReleaseStock`).
- `Processing` $\rightarrow$ `Fulfilled`: Permanent deduction (`inventoryService.DeductStock`) with outbound stock movement.
- `Processing` $\rightarrow$ `Cancelled`: Releases reserved stock (`inventoryService.ReleaseStock`).
- All other transitions are rejected with HTTP 400 Bad Request.

## 3. Step-by-Step Execution Plan

### Step 3.1: Implement `OrderRepository`
Create `services/api/internal/repository/order_repository.go`:
- Transactional order creation with order items.
- Eager-loading of `Items` on query.
- Atomic status updates.

### Step 3.2: Implement `OrderService`
Create `services/api/internal/core/service/order_service.go`:
- Calculates subtotal and line items using `decimal.Decimal`.
- Enforces state transition guard matrix.
- Coordinates with `IInventoryService` to hold, release, and deduct stock.
- Associates `source` (`web_form`, `ai_draft`) and `draft_id`.

### Step 3.3: Define DTOs & Controller
Create `services/api/internal/present/http/dto/order_dto.go` and `controller/order_controller.go`:
- Full Swagger annotations: `@Summary`, `@Description`, `@Tags Orders`, `@Success 200 {object} response.Response[...]`.
- Standardized `response.Response[T]` wrappers.

### Step 3.4: Route Registration & Uber Fx Wiring
- Wire into `internal/bootstrap/` (`repository.go`, `service.go`, `controller.go`).
- Register endpoints in router.

### Step 3.5: Testing & Verification
- Unit tests in `services/api/internal/core/service/order_service_test.go`.
- Compile and run tests with `go test -v ./...`.
